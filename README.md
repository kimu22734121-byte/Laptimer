# マイコンカー ラップタイマー

スマホのカメラ映像で、画面上に引いた計測ラインをマイコンカーが通過したことを検知し、ラップタイムを記録する Web アプリです。
インストール不要・サーバー不要（HTML / CSS / JavaScript のみ）で、GitHub Pages でそのまま公開できます。

## 機能

- スマホのカメラ映像（背面カメラ優先）上に計測ラインを表示し、両端の丸をドラッグして位置・角度を調整
- ライン上の画素の明るさ変化から車の通過を検知
- **計測待機** → 1回目の通過で計測開始 → 以降は通過ごとにラップを記録
- 一度検知したら設定秒数（初期値 1 秒）は再検知しない（さらに、ラインから車が離れるまで次を受け付けない）
- ラップ一覧（新しい順）、ベストラップの強調表示、ベストとの差、合計タイム
- 通過音・バイブ・画面フラッシュで通知、計測中は画面スリープを防止（対応ブラウザのみ）
- フレームレート（自動 / 30 / 60 / 120 / 240fps）・感度・しきい値・再検知しない時間・ラインの太さを調整可能（設定と記録はブラウザに保存）
- 記録をクリップボードにコピー
- 縦画面・横画面の両方に対応（スマホ／iPad）。横画面では左にカメラ、右にタイマーとラップ一覧を並べて表示

## 使い方

1. 公開した URL をスマホのブラウザ（iPhone は Safari、Android は Chrome 推奨）で開く
2. **カメラ起動** を押し、カメラの使用を許可する
3. スマホをスタンドなどで固定し、計測ラインの両端の丸をドラッグして **コースの幅を横切る** ように配置する
   （線の中央付近をドラッグすると線全体を移動できます。「ライン固定」で誤操作を防げます）
4. 車をラインの少し手前に置き、**計測待機** を押す
5. 車をスタートさせると、最初の通過で計測開始。以降、通過ごとにラップが記録されます
6. 終わったら **計測停止**。**リセット** で記録を消去します

### 画面の向きについて

- 縦画面・横画面どちらでも使えます。iPad は横向きで置くとカメラ映像を大きく表示できます
- 画面を回転するとカメラ映像の縦横比が変わるため、計測ラインの位置がずれることがあります。**向きを決めてからラインを合わせ、計測中は回転させない**でください（端末の画面回転ロックの利用がおすすめです）

### 検知がうまくいかないとき

画面下の青いバーが「ライン上で変化している割合」、黄色の目印が検知する基準（感度）です。

- **誤検知する**（車が来ていないのに記録される）：「検知感度」の数値を上げる／「明るさ差のしきい値」を上げる
- **検知しない**：「検知感度」の数値を下げる／「明るさ差のしきい値」を下げる
- ラインは長すぎるとライン上に占める車の割合が小さくなるので、コース幅程度に短く引くと安定します
- コースと車の色・明るさの差が大きいほど確実に検知できます。影や人の手が入らない位置にしてください
- 計測精度はフレームレートで決まります（30fps で約 ±0.03 秒、60fps で約 ±0.02 秒、120fps で約 ±0.01 秒）。映像左上に実際のフレームレートが表示されます

### フレームレートの選択

設定の「フレームレート」で **自動 / 30 / 60 / 120 / 240** から選べます（カメラを止めずに切り替わります）。

- **自動**：そのカメラが対応する最大のフレームレート（240 まで）を使います
- 選んだ値にカメラが対応していない場合は、オレンジ色で「対応していません」と表示し、近い値で動作します。設定欄にそのカメラの最大値も表示されます
- 解析は画面の表示に合わせて行うため、画面のリフレッシュレート（多くの端末で 60Hz、ProMotion 搭載の iPad Pro などは 120Hz）を超えるフレームは解析できません。その場合、映像左上に「カメラ 240 / 解析 60 fps」のように両方の値が表示されます
- ブラウザ（特に iPhone / iPad の Safari）では、カメラアプリのスローモーションのような 120 / 240fps は使えないことが多いです

## GitHub Pages での公開手順

カメラは HTTPS でないと使えませんが、GitHub Pages は自動で HTTPS になるので問題ありません。

1. このリポジトリのファイル（`index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `icon.svg`, `.nojekyll`）を
   `main` ブランチのルートに置く（作業ブランチの場合はプルリクエストを作って `main` にマージ）
2. GitHub でリポジトリを開き、**Settings** → 左メニューの **Pages** を開く
3. **Build and deployment** の **Source** で **Deploy from a branch** を選ぶ
4. **Branch** で `main` と `/ (root)` を選んで **Save**
5. 1〜2 分待ってページを再読み込みすると、上部に公開 URL が表示されます
   - 例：`https://<ユーザー名>.github.io/<リポジトリ名>/`
6. スマホでその URL を開いて使います。ブラウザの「ホーム画面に追加」をするとアプリのように全画面で使えます

> 無料プランで GitHub Pages を使うにはリポジトリが **Public** である必要があります（Private リポジトリでの公開は有料プラン）。

以降は `main` ブランチに変更を push するたびに自動で再公開されます。

## ローカルで試す場合

```sh
python3 -m http.server 8000
```

PC のブラウザで `http://localhost:8000` を開くと、PC の Web カメラで動作確認できます（`localhost` は HTTP でもカメラが使えます）。
スマホから PC の IP アドレスで開く場合は HTTPS が必要なため、GitHub Pages での確認がおすすめです。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面構成 |
| `style.css` | デザイン（縦画面・横画面対応） |
| `app.js` | カメラ制御・通過検知・タイム計測 |
| `manifest.webmanifest`, `icon.svg` | ホーム画面追加用 |
| `.nojekyll` | GitHub Pages で Jekyll 処理を無効化 |
